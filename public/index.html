Markdown Format Guide

Each flashcard is defined by a header block in your markdown file:

### **Front text**                Translation

Example sentence | Example translation

Structure:

  • Header line (h1-h5): The bold text becomes the card front, any following text becomes the translation
  • Example line: Uses | as separator between example sentence and its translation

Multiple Cards:

  • A single file can contain multiple cards
  • Each new header (# to #####) starts a new block/card
  • Content between headers belongs to that card's block

Example:

### **Ich bin der Ansicht, dass …**    Я считаю, что…

Ich bin der Ansicht, dass Kommunikation wichtig ist. | Я считаю, что коммуникация важна.

### **Aus meiner Sicht ist es wichtig, …**    С моей точки зрения важно…

Aus meiner Sicht ist es wichtig, Beruf und Familie zu vereinbaren. | С моей точки зрения важно совмещать работу и семью.
